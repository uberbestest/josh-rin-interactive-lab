## Why this lab exists

An experiment is more useful when other people can operate it. The instruments make it possible to test assumptions and encounter the boundaries of a result directly. The gallery is an evolving project record rather than a certification service or a claim that every question is settled.

**Evidence discipline:** distinguish recorded checks from independent validation, inference from observation, and open questions from demonstrated facts. Each instrument has its own limitations; missing evidence stays missing.

**Public-safety boundary:** this repository contains only selected exhibit material. Continuity-related research, personal information, credentials, and private research architecture are not part of the public gallery.

**How to preview locally:** from the repository root, run `python -m http.server 8000` and open `http://localhost:8000/`. The current gallery and workbench do not require external dependencies.
