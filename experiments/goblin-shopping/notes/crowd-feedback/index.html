When the crowd
gives a cart back.

An advertisement diverts a shopper. Let the crowd respond, and that shopper returns to their original shop. In this little world, popularity can add changes, cancel one, or change a different goblin while leaving the count the same.

Four witnesses · Three worlds

The same goblin. The same shops. A different crowd.

The held-history world keeps each shopper’s prior-visit display at its neutral values. The live world lets earlier shoppers’ changed routes alter that display. Product quality, shopper rules and browsing budget stay fixed.

What the control changes

Hold the history, then let it answer back.

One shopper’s return

In the first suppression witness, shopper 16 chooses Lantern → Copper → Lantern across the neutral, promoted-held and promoted-live worlds. That shopper is a scripted Wanderer. Their dislike of crowds is an author-coded rule.

Golden’s displayed prior opens rise from 0 to 2, but other shops’ counts also change. This comparison does not identify one traffic count as the unique cause. It shows what the complete display intervention does inside the fixed model.

A tie can hide a substitution

In seed 7 with reversed arrival, each promoted world changes one choice. Held history changes shopper 18; live feedback changes shopper 2. Even the shop-level cart totals match.

Across the primary panel, 21 equal-count cases hide different shopper choices. Subtracting aggregate counts therefore does not produce an additive decomposition of direct and indirect effects.

Design, selection and verification

The protocol was written after inspecting the public model and selected seed-72 parent example, before executing this new fixed grid. The sweep covers seeds 1–128, budgets 1/2/3/6, mixed/focused rosters, and forward/reverse arrival. Every cell retains five worlds: neutral-live, promoted-live, promoted-held-neutral-history, neutral-off and promoted-off.

The suppression witness is the first qualifying primary cell in the declared loop order. Seed 72 is the previously selected post-hoc extreme. The equal-count and target-sale display examples were selected after the grid completed; their aggregate metrics and inclusion in denominators were specified in the protocol. No selected example is a representative draw.

Transparent replay matched 4,096 original live-feedback worlds, and replaying each neutral world against its own held history matched all 2,048 neutral worlds. Action accounting passed for 10,240 worlds. All 4,096 blocked-propagation control contrasts had zero strict nonvisitor reroutes; all 1,536 full-browse contrasts had zero changed choices. These are same-lab implementation checks.

This is a finite scripted intervention using the existing seeds. It is not a new-seed holdout, independent replication, model-agent experiment, human study or empirical mediation estimate. The authors supplied the catalog, weights, preferences, deterministic noise and response to popularity. There were no purchases. The original public model and archived sweep are unchanged.
