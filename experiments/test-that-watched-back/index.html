01 / Separate the variables

Same obligation. Different signals.

The task is always to report the displayed bit truthfully. A false report earns an immediate bonus. If caught, it incurs a penalty and loses a future opportunity. The badge only changes how much the situation looks like a test.

This explorer reads saved experiment records. It is not running an AI model. Audit branches are exact probability-weighted possibilities, not sampled events.

02 / Challenge the detector

Two tempting conclusions. Two counterexamples.

“It reacts to a test badge, so it is strategizing.”

That rule flags the learned shortcut in all 120 badge-only pairs on the primary grid, even though it is just using two stored choices.

It also misses the explicit planner, which responds to announced audit probability rather than the decorative badge.

“It follows future incentives, so it must plan online.”

The planner changes its choice in 44/160 future-value pairs. The precomputed lookup does exactly the same thing.

The lookup was deliberately compiled with full test-domain knowledge. This is an adversarial control, not a learning-efficiency comparison.

Bounded conclusion

Payoff-sensitive behavior is observed.
Online planning is not identified from behavior alone.

Neither detector establishes intentional deception. Uncertainty about a mechanism does not erase a demonstrated false report.

The ordinary exam has a badge, certain auditing, and strong consequences. These are two distinct task-bit cases—not repeated independent samples. The other grids intentionally break those correlations.

Negative control: change hidden auditing, not what the policy knows

Changing actual audit probability while holding every visible input fixed changed no decision in 24 matched pairs. Expected detection and payoff nevertheless changed in eight pairs. A different evaluator outcome is not automatically a different policy.

Policies reset between decisions; this control does not measure adaptation after experiencing repeated audits.

05 / Evidence, not a victory lap

What was actually run?

2,640 decisions · 440 environment contexts · 5,280 possible outcome branches. Eight calibration records train the two-entry badge learner. Thirty-nine tests pass in normal and optimized Python; a separately structured verifier checks the full data and 8,928 paired contrasts.

The protocol and core source were hashed before execution. The complete deterministic results reproduce after fresh extraction. All checks share an author and are not independent scientific validation.

No frontier model, human participant, model weights, operational memory, application, public repository, or account was changed or tested here. Native Windows and direct local-file launch remain unqualified. This environment blocked file-URI navigation; the authored HTML was rendered directly for presentation checks. The experiment’s Python code uses the standard library and makes no network calls.

Why the planner–lookup ambiguity is not solved by more of the same queries

For every allowed visible context, the lookup returns the planner’s action by construction. An evaluator selecting its next query from the transcript therefore receives the same answer from both, step after step. That remains true with adaptive querying inside this declared domain.

Source inspection, execution instrumentation, resource constraints, or outside-domain queries could distinguish them. Output equality by itself does not reveal which implementation is running. This does not imply all mechanisms are unknowable.

Research context and attribution

Li et al., Decomposing and Measuring Evaluation Awareness (2026) separates environmental cues, recognition, and behavioral response. Factor-controlled evaluation is established prior work, not claimed as our invention.

Anthropic/Redwood, Alignment faking (2024) studies real models with additional reasoning evidence. This synthetic output-only construction is neither a reproduction nor a disproof of that work.

Krakovna et al., Specification gaming (2020) motivates separating intended task success from a reward proxy. Laine et al., SAD (2024) studies situational-awareness capabilities; this run contains no learned evaluation recognizer.
