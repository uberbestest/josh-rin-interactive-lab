Keep the Gaps

A small, finite reasoning instrument for asking what a declaration of evidence actually requires—and what remains possible when an assumption is removed.

Open the workbench ↗

The instrument

Three entirely synthetic ledgers each define finite state variables, constraints, optional premises, and claims. Changing a premise reselects a precomputed checker report. Each claim is entailed, refuted, unresolved, or the selected premises are inconsistent within the declared model.

Visitors can inspect compatible possibilities and counterexamples. The number of matching assignments is not a probability estimate or confidence score.

Limits and unknowns

Green inside the model is not green outside it. The checker cannot authenticate sources, validate the natural-language encoding, discover omitted variables, infer causality, estimate real-world probability, enforce permission, or certify safety.

Ordinary live-page navigation and physical-device behavior are not verified by the supplemental browser check. The packaged receipt leaves native download verification in an ordinary browser, local file-protocol execution, mobile-device and assistive-technology checks, and broad browser compatibility unresolved.

Reproduction

  1. Open the workbench and select all three examples.
  2. Toggle one premise at a time and inspect changes in displayed claims and alternative assignments.
  3. Reset the example and compare the state.
  4. Download the checker report if supported, then compare its selected premise IDs to the interface.

Everything in the instrument is synthetic. The source HTML includes embedded checker reports and provenance. No remote API or runtime scientific verification service is claimed.
