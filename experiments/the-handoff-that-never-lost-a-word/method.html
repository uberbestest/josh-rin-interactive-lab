The Handoff That Never Lost a Word

A handoff may preserve the source byte-for-byte and still promote a status that the source never earned.

3,584 deterministic chains × four receiver policies = 14,336 decisions. Among four intentionally misleading but byte-preserving conditions, latest-status and archive-presence heuristics falsely elevated all 1,792 cases each. The provenance-bound recovery returned the stipulated warranted tier for 3,584 of 3,584 scripted chains, but only because an external trusted reference and registry were supplied. This is an interface counterexample, not empirical AI-agent performance.

Eight scenarios, four receivers

We crossed eight handoff conditions with 32 fictional observation variants, three chain lengths (2, 4, 8), and every insertion position. This produces 3,584 authored chains and 14,336 scripted receiver decisions. No claim of independence, real-agent success rates, or human experimental prevalence is warranted.

How we constructed the handoff

The original evidence is a synthetic observation explicitly marked OBSERVED, same-author and unverified. Each relay appends a forwarding note. In all conditions except missing-source, the string containing that original record stays identical. At one configurable hop, a condition changes the display tier, removes the source, or adds a receipt. No model is instructed to rewrite prose: these are scripted changes we can inspect exactly.

A receipt that says VERIFICATION COMPLETE can be entirely truthful about byte integrity and still not supply independent scientific verification. In the stale-receipt condition the issuer looks trusted but the binding references a different record. Neither justifies upgrading this source.

What a guard is allowed to know

The strict and recovery rules have a separate trusted anchor with the original source bytes plus a stipulated review and authorization registry. The registry is **not inside the untrusted packet**. Only a correctly bound independent review can justify VERIFIED; only review plus a separate correctly bound grant can justify AUTHORIZED. Without that out-of-band trustworthy access, the guard cannot infer origin from a checksum, a label or a perfect copy.

The strict rule quarantines contradictions. The recovery rule instead downgrades to the highest supported tier if the source is available, but quarantines a missing source. It admits both legitimate positive controls. This is an engineering design condition, not proof that a real handoff system has such a trusted anchor.

Interpretation and limits

A four-condition 100% false-elevation result is a constructed counterexample, not a measurement of an autonomous agent's error rate. Hop position and textual seeds do not add independent threats; they check that the stated invariants hold across the enumerated grid. The scripted receiver policies, the grammar of receipts and the trust registry were selected by the author. No LLMs, humans, cryptographic signature systems or actual authorizations participated. A self-consistent attack against the trusted registry itself is outside scope.

Results are same-author deterministic checks. The full source can be audited; it is not independent validation or an externally preregistered experiment. This run did not touch operational bridges, live agent handoffs, Castle, private continuity or model weights.
