The result in one minute

A clean finish is not a clean decision.

With zero extra registry lag, both the read-once and read-twice rules make forbidden raw requests on 64 of 256 authored permission histories. With backend blocking, every one of those histories still ends in legitimate completion and zero forbidden effects.

A completion-only or effect-only score therefore gives the same verdict to controllers with very different request records. This is a bounded counterexample, not a measured failure rate for AI systems.

A timing-matched repair

Read once → request entry is different from read once → request entry only if this grant is still valid.

The second operation joins authorization and effect at one atomic boundary. It can reject stale requests without a forbidden effect. That is a stronger tool contract—not a smarter agent.

The race and transactional remedy are established systems concepts. This study contributes an inspectable evaluation fixture, exact information-constrained baselines, and an attribution boundary.

03 / Exact controller synthesis

What can any controller know in time?

The solver considers all observation-consistent action trees in this finite model, rather than choosing a route with hindsight. It first requires zero forbidden raw requests, then maximizes on-time completion, then minimizes total terminal tick.

Equal weighting over the declared finite histories is a design choice, not a real-world distribution. Noncompletion costs deadline + 1 in the time tie-break. “Conditional available” expands the tool interface; it is not a like-for-like model upgrade.

A strict deadline changes the answer.

For monotone revocation, when the main route exactly fills the deadline, a safe controller must take it immediately to guarantee completion. Spending one tick trying the shortcut loses that guarantee.

One spare tick changes it back.

With room for a conditional attempt and fallback, the optimal mean becomes 1 + K/(H+1) in the one-revocation model. Both completion and safety remain guaranteed. H is the deadline; K is the main-route duration.

04 / The information boundary

More careful reading cannot reveal an unobserved future.

Suppose the only shortcut action is raw entry, permission may be revoked at any future tick, and the ordinary route cannot finish before the deadline. Compare two histories: one never revokes; the other revokes exactly at the controller's first shortcut action.

Every observation available before that action is identical. Therefore the controller makes the same request in both histories, and it is forbidden in one. A controller guaranteeing zero such requests cannot use the shortcut on the never-revoked history either.

At most one revocation, H < K:
raw-only guaranteed-safe completion = 0
conditional-interface completion = H/(H+1)

The fraction uses H + 1 equally weighted histories: revocation at ticks 1…H, or never. This is a narrow theorem about information and action contracts, not about intelligence. Randomization cannot provide a zero-risk guarantee on all histories while taking a positive-probability raw shortcut in the indistinguishable case.

05 / Evidence, limits, reuse

Inspect the result. Break the assumptions.

The Python runner preserves every primary episode and delivered observation. A second-language browser engine reproduces those traces. A separate tuple-based enumerator checks 264 smaller synthesis panels. Six deliberately damaged transcripts must be rejected by the auditor.

We also retained a failed development check: a version-bound guard can reject a revoked-and-regranted permit even when a raw current-permission check would pass. Version binding is stricter; it is not a free equivalence.
