# Development record
The original locally frozen design is retained as protocol-initial.json and design-freeze.json. It was not externally preregistered. An initial eight-policy execution produced 12,288 episodes and passed 35 tests. No result from that intermediate run was published as the final study.

Before public release, a ninth timing-matched control, inspect_guard, was added: it has the same authentic read and action timing as inspect_once but uses the conditional entry contract. This prevents the repair comparison from depending solely on the atomic_once policy acting a tick earlier. The final primary corpus has 13,824 episodes. The 1,050 optimization panels are unchanged. One new matched-control test brings the suite to 36 distinct tests. Baseline code was not edited.

The first matched-control test incorrectly expected identical paths in *all* blocked worlds. The new test exposed a scope mistake: a version-bound guard can reject a revoked-and-regranted (ABA) permit even when raw current-permission entry would be valid. The test was narrowed to forbidden-raw-request worlds, where blocking and conditional rejection should indeed have identical effects and timing. The broader equal-path claim is withdrawn; epoch binding is intentionally stricter than a current-permission boolean. The failed log is retained as development-test-failure.txt. No engine or numerical outputs were changed for this correction.
