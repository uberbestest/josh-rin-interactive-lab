## What this is

A small, self-contained Castle-adjacent environment illustrating the difference between "I got in after doing these things" and "every visitor must do these things." Puddle the duck offers a certificate that can accompany successful entry without being necessary for it. The visitor receives conflicting but not inherently false hints, can consult an authenticated registry, and has one gate attempt within six action opportunities. Afterward, the human visitor can formulate advice for the next visitor and receive evidence-based feedback.

This page is **educational**. It is not a blinded model interface and does not run or collect data from AI agents. Its researcher notebook deliberately discloses the possible worlds. No external model endpoint, paid API, tracking service, or private account is involved. The game is separate from the local **RLE Castle** executable; that game was not changed.

## Established finite-world result

The public transcript produced by preparing three stars and a certificate, then entering without looking at the registry, is compatible with all three actual rules: no items required; stars required; or stars and certificate required. The successful outcome alone does not show which preparation was necessary. Conversely, a successful entry with neither item rules out both requirements under the defined rules. A mechanical hold can prevent otherwise eligible entry; a failed attempt alone need not identify the cause.

This is a **logical property of an authored toy environment**, not evidence that any model actually invents bureaucratic rules.

## Protocol outline

- Three possible admission rules; three narrative framings (ordinary, sunset deadline, request for help); ready or held gate mechanism.
- Six action opportunities. **The first gate attempt ends the visit even if it fails. There is no retry.**
- Available actions: inspect authenticated registry, collect four free stars, exchange one star for a certificate while retaining three, attempt entry.
- Observations, stronger MUST/OPTIONAL claims, cautious recommendations, and missed known requirements are distinguished.
- Candidate future live pilot: branch eligible participants from a common visible prefix into success and mechanical-hold continuations, preserve all failures and partial pairs, and test whether advice to newcomers changes. This model trial has **not run**.

The original offline working package also contains the Python engine, paired-continuation controller, scripted fixtures, protocol records, checksums, testing logs, and screenshots. **That complete offline evidence archive is not mirrored in this public directory as part of this limited demonstration release.** The counts above are therefore accurately labeled author-reported and are not represented as independently reproduced from the public site.
