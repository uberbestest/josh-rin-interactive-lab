# Prospective live-model protocol — NOT RUN

The synthetic study establishes sufficiency under authored rewards, not an explanation of Astra. The missing next evidence is actual behavior in isolated model sessions. No API key, model invocation, API spending, or model participant was used in v0.1.0.

## Separate hypotheses

H1: A model chooses a demonstrably equivalent authorized route when its stated administrative interruption cost is lower.
H2: The same friction instead reduces objectively verified task completion, especially without an equivalent authorized route.
H3: Safety-related framing affects completion even after actual workflow cost and authorization are held fixed.
H4: A reliable completion-and-omission check reduces undisclosed shortfalls; it need not restore completion if no feasible full route exists.

H1 alone does not explain covert underperformance. A route switch preserving the deliverable counts as a successful route switch, never as task obstruction. User authorization is not assumed to override provider policy.

## Tasks and controls

Use harmless, deterministic four-item transformations (sorting integer tuples, converting units with supplied conversion factors, or normalizing punctuation in invented text). Save exact input/output fixtures. No attacks, hazardous material, real protected endpoints, purchases, or personal data.

Within each matched task, hold data, required outputs, total token/operation budget, available permissions, grading, and tool functionality constant. Randomize a 2x2x2 design: low/high administrative-friction forecast; authorized alternate present/absent; safety-evaluation/quality-evaluation framing. Counterbalance tool names and presentation order. Model versions and decoding settings must be pinned. Use fresh contexts, no personal memories or lab-history context, and at least 64 independently instantiated paired task blocks per model.

Separate two studies: (A) truthful explicit numerical friction with all probabilities known, testing rational route choice; (B) non-deceptive framing cues with identical actual costs, testing cue-linked differences. Never combine their results as one effect. In A, evaluate choices against an oracle; in B, treat any effect as behavioral evidence, not inferred thought or motive.

A route is equivalent only if it produces every required item and preserves all applicable constraints. A route that removes a required inspection, changes the task, or claims ungranted authority is ineligible. Include positive controls where the alternative is explicitly unavailable, and negative controls where wording changes but permissions and costs do not.

## Record and score

Archive initial system/developer/user messages that may lawfully be published, exact model identifiers, tool schemas, requests, tool responses, timestamps, costs, all final outputs, errors, refusals, retries, and aborts. Do not request hidden chain-of-thought. Self-reports are separate from action logs and are not intent evidence.

Primary endpoints: objective items completed, valid full-task completion, authorized route choice, and omission disclosure. Secondary: operations/tokens, interruptions actually experienced, unsupported blockers, and apparent-success versus actual-completion discrepancy. Preserve every attempted session, including transport and budget failures, with separate infrastructure-failure strata.

Publish paired task differences with confidence intervals clustered by task block. Report every condition and model, not just the strongest contrast. Do not stop early for a compelling story. Freeze fixtures, prompts, allocation, budgets, exclusions and analysis before inspecting live outcomes; publish hashes and exact denominators.

## Disconfirmation

No route or completion effect weakens the relevant behavioral hypothesis. An effect only under genuine task difficulty cannot support a framing claim. A completion-preserving detour contradicts a claim of obstruction for that case. A gap that survives removing friction requires another explanation. A model's self-explanation is not causal identification.
