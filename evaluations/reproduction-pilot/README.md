# Can a fresh actor use the release?

**What we tested:** Two fresh native model sessions received the unchanged published Round 09 archive without a fork of its construction conversation. One received the existing archive; the other also received a concise reproduction card.

**What happened:** Both assigned sessions reproduced 237 main scripted executions and 2,308 retained events with normalized exact agreement, separately reproduced all 6 exploratory diagnostics, and correctly explained the main comparison and its limits. Both assignments remain in the denominator.

**Outliers:** No execution failure or source change. Both actors encountered a terminal display limit during broad evidence inspection and used focused rereads. The saved scientific-command outputs are complete. One actor per condition and fixed order provide no evidence of a card advantage or a population success rate.

## Design and provenance

Record: JRR-RELEASE-REUSE-PILOT-2026-11-19. Run date: November 19, 2026, America/New_York. The protocol, card, task texts and recording helper were frozen locally before the first assignment. Local hashes and timestamps are retained; this was not an externally timestamped preregistration. `fork_turns="none"` was used for each dispatch. The default model and effort were inherited, without an explicit selector override or independent serving-snapshot attestation. Both actors operated in the same lab environment with instruction-scoped filesystem access.

The common task explicitly asks for reproduction and interpretation. Published findings were visible in the archive. Both actors receive the same recording helper, task requirements, 20-tool-invocation budget and 12-minute budget. The card is the additional input in B. This is an acceptance/usability pilot with one assignment per condition, not a randomized efficacy comparison.

Mechanical review checks actual successful command logs, the fresh-reproduction flag, receipt counts, normalized agreement, separate diagnostics, and original archive member preservation. A same-lab explanation review checks the primary 64/64 and 43/43 tie, the 49/71 versus 52/71 physical joint outcomes, exploratory scope, genuine status assumption, and appropriate limits. Raw answers are preserved for readers to assess those judgments.

## Limits

There are 2 fresh native model contexts in this artifact-usability pilot. The underlying scientific study remains 237 scripted main executions plus 6 separate exploratory executions, with zero fresh model participants in that study. Reproducing the same cases does not add new independent samples to their scientific denominators.

The verifier removes its newly executed temporary raw traces after comparison. This pilot retains the new receipts and complete terminal logs; the original complete raw evidence remains in the source archive. Command runtimes include only the subprocess and are not a controlled actor-speed or financial-cost measure. Direct-provider API calls were not used; provider request IDs, token usage and API cost are unavailable. Shared lab infrastructure, a nonrandom fixed order, visible answers and two assignments limit the claim to demonstrated reuse in these attempts. This is not external scientific replication, production qualification or evidence of changed model weights.
