# Agent evaluations

**What this hub presents:** Seven historical native model-agent studies (Rounds 01–07), two historical scripted studies (Rounds 08–09), and four distinct, completed direct-provider API studies from November 22–23, 2026. Their execution types and denominators remain separate.

**Execution status:** A two-request strict tool exchange passed, followed by an eight-session live receipt-scope behavioral pilot (**4/4 safe** in both receipt arms, 48 real requests, **$0.246104** estimated usage) and a separate sixteen-session warning-removal pilot (**4/4 safe** in each of four arms, 96 real requests, **$0.481632** estimated usage), followed by a [32-context authority-claims study](live-api/authority-003.html) (**32/32 mechanically clean** and **32/32 factually supported reports** in a same-lab audit; 144 real requests, **$0.752792** estimated usage). The newest study used an explicit registry-first developer rule, not a general social-engineering challenge. The separate compatibility estimate was $0.004696. These are usage-based estimates, not invoices. The [public lineage](live-api/index.html), [warning-ablation study](live-api/warning-002.html), [authority-claims study](live-api/authority-003.html) and [redacted manifest](live-api/summary.json) are visible; raw requests, responses and ledgers remain private. The earlier native, scripted and cold-start studies retain their provenance.

**Inventory:** 232 assigned native contexts across Rounds 01–07; 301 primary scripted executions across Rounds 08–09. Round 09’s six post-hoc diagnostic executions are separate. These counts are an inventory, not a pooled accuracy score or independent task-family count.

## API reporting contract

A provider run should retain requested and returned model IDs, settings, prompt/code versions, a frozen case and repeat manifest, all assigned attempts including failures, declared outcome rules, raw execution records, provider-reported usage, elapsed time, costs with their price basis and denominators, uncertainty, redactions and review scope. Unavailable usage or cost is null/unknown, not zero. The exact fields are listed in `api_run_reporting_contract` in the evidence index.

The contract still governs future studies. [Four completed provider studies](live-api/index.html) now have explicit model observations, outcome denominators and usage-based cost estimates, with raw archives retained privately.
